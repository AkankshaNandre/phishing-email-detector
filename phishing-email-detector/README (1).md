# Phishing Email Detector

A beginner cybersecurity project built with Python and Jupyter Notebook to detect suspicious phishing emails.

## Objective

This project analyzes email text and identifies possible phishing attempts using keyword and link detection.

## Features

- Detects suspicious phishing keywords
- Detects suspicious links
- Calculates phishing risk score
- Classifies emails as:
  - Low Risk
  - Medium Risk
  - High Risk

## Technologies Used

- Python
- Jupyter Notebook

## Example Suspicious Indicators

- urgent
- verify account
- click here
- bank
- password
- suspicious links

## Security Relevance

Phishing attacks are one of the most common cybersecurity threats.

This project demonstrates beginner-level phishing detection and security analysis concepts.
